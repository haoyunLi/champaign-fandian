# 饭点 · 香槟吃什么

和群友一起选餐馆，也能帮去不了的人带一份饭。

**[打开饭点](https://champaign-fandian.haoyun963.chatgpt.site/)** · [查看历史](https://champaign-fandian.haoyun963.chatgpt.site/history) · [GitHub Pages 入口](https://haoyunli.github.io/champaign-fandian/)

## 怎么用

1. 设置一次群昵称（可选 ChatGPT 登录以跨设备同步），选几家餐馆，发起「自主投票」或「随机抽签」。
2. 把链接发到微信群，大家打开参与；有票后，任何人都可以确定餐馆。
3. 需要带饭的人登记菜品，朋友认领、确认下单并标记已带回。开始下单后可以停止加单，售罄时可申请换菜并由带饭人确认。

创建时可选香槟时间的投票截止，到点自动确定结果，无人投票则显示未产生结果。首页展示自己的带饭安排和未读更新；带饭人可按菜品与备注汇总待下单清单，登记时可填入自己在该店上次点过的菜。

菜单窗口可以直接登记带饭，对照图片填写，关闭后保留草稿。旧饭局可切换到最新菜单；首页可搜索餐馆、批量勾选并保存自己的常用餐馆池。带饭人填写预计时间和取餐地点后，收餐人会在登记旁看到；「复制群通知」可整理当前进度，粘贴到微信群。

页面会显示发起人、投票人的昵称，以及谁登记、谁来带、哪些已经带回。点击顶部用户名可修改自己的昵称，相关记录会同步更新。首页可继续饭局，历史中可找回记录或再来一局。

## 开发与维护

需要 Node.js 24。

```sh
npm run install:ci
npm run build
npm run db:migrate:local
npm start
```

## 身份与分享

同一浏览器会自动记住昵称，不用每顿重复填写。点击顶部用户名可选择 **通过 ChatGPT 登录**；首次登录会绑定本机已有昵称与饭局记录，以后在其他设备登录同一账号即可找回。昵称仍可随时修改，群友看不到你的登录邮箱。

不登录也能使用，但游客身份跟随浏览器。已有账号登录其他浏览器时使用账号记录，不自动合并那个浏览器的其他游客记录；原游客记录在退出后仍可查看。账号退出后，其原游客凭据不能再管理账号记录。

持饭局链接的人可以查看该轮昵称、投票和带饭备注。此工具只协调带饭，不向餐馆下单、扣费或自动发送微信消息。
