# 饭点 · 香槟今天吃什么

适合发到微信群的中文餐馆随机投票与带饭登记网页。

- 所有人共用餐馆库，可添加、删除和修改名称、类型、地址。删除前需确认，删除后可撤销；已开始的投票及带饭记录不受影响。
- 每位发起人独立勾选本轮候选；开始后名单固定。
- 「历史记录」可分页查看当前浏览器发起的全部投票、结果和带饭清单。仅发起人可删除整轮记录；删除后进入回收站，原链接不可访问，也不再接收投票或带饭操作。可撤销或在回收站恢复，保留原结果、票数和带饭状态。
- 群友输入昵称，服务器等概率抽取餐馆并自动计一票。
- 同一浏览器每轮一票，同一昵称每轮不可重复。没有接入微信身份认证；更换浏览器或清除 Cookie 会被视为新的访客，也会失去原来的发起人权限。
- 发起人结束后，最高票获胜，平票在并列餐馆中随机选一家；结果固定。
- 餐馆确定后，可以登记菜名、份数和备注。朋友认领带饭，并标记已带回。未认领的登记可由本人取消。
- 投票、餐馆和带饭记录保存在共享 D1 数据库。浏览器 Cookie 仅用于识别访客，不保存投票或带饭记录。

默认餐馆：Culver’s、Raising Cane’s、上海菜（店名可补全）、Chick-fil-A、Kung Fu BBQ（盒饭）、Chipotle。没有 Panda Express。

## 本地运行

需要 Node.js 22.13 或更新版本。`npm run install:ci` 安装依赖；`npm run build` 生成 Cloudflare Worker。按 `drizzle/` 中的顺序将迁移应用到本地 D1，然后 `npm run start` 预览。

数据库结构位于 `db/schema.ts`，所有 API 使用预处理语句。投票唯一约束、结束投票及认领更新在数据库中保证原子性。订单提交采用请求 ID 去重。房间状态有递增版本，前端拒绝过期响应。

已用本地测试数据验证共享编辑、投票池快照、22 人投票、并发重复投票、昵称去重、发起人权限、固定赢家、结束后拒票、带饭登记重试去重、同时认领与带回权限。另完成手机界面流程检查。历史功能已验证同时间分页、身份隔离、删除后七类操作拒绝、进行中和已结束投票恢复、完整保留带饭认领状态，以及删除与投票并发。

带饭功能仅用于群内协调，不会向餐馆下单、扣费或发送微信消息。拥有本轮链接的人可以查看群昵称、投票和带饭备注。
